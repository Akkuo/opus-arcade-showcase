# Claude Opus 5.5 — 2D × 3D 網頁遊戲實測展間

8 款由 Claude Opus 5.5 撰寫的原創網頁遊戲入口頁，全站零外部美術與音效素材檔。

- **線上展間**：https://akkuo.github.io/opus-arcade-showcase/
- **對照組（Gemini 4 Neon 版）**：https://akkuo.github.io/pixel-arcade-showcase/

| 遊戲 | 類型／技術 | 線上試玩 |
|---|---|---|
| TIDEKEEPER 潮汐守望者 | 橫向平台，Canvas 2D | https://akkuo.github.io/tidekeeper/ |
| TIDEKEEPER Pixi 版 | 同上，PixiJS v8 | https://akkuo.github.io/tidekeeper-pixi/ |
| LANTERN HOLLOW 燈籠谷 | 俯視冒險，Canvas 2D | https://akkuo.github.io/lantern-hollow/ |
| LANTERN HOLLOW Pixi 版 | 同上，PixiJS v8 | https://akkuo.github.io/lantern-hollow-pixi/ |
| SKYSEED 種子遠航 | 3D 滑翔，Three.js | https://akkuo.github.io/skyseed/ |
| TOPPLE WORKS 傾倒工坊 | 3D 物理倒塌，Three.js + cannon-es | https://akkuo.github.io/topple-works/ |
| TERRACE BLOOM 梯田復甦 | 第一人稱修復，Three.js | https://akkuo.github.io/terrace-bloom/ |
| FROSTHOLD 凍土方塊 | 第一人稱體素生存，Three.js | https://akkuo.github.io/frosthold/ |

單一 `index.html`，封面動畫皆以 Canvas 2D 程式即時繪製。
